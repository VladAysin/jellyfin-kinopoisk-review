# Jellyfin Kinopoisk Ratings

Плагин предлагает оценить просмотренное по шкале 1–10 и отправляет оценку в личный аккаунт Кинопоиска. Версия 0.3.0 рассчитана на **Jellyfin Server 10.11.5**. Подключение аккаунта и очередь находятся в настройках плагина; плавающей кнопки «КП» больше нет. Окно оценки проверено в браузере и отдельном **Jellyfin Media Player 1.12.0 для Linux** с воспроизведением через MPV. Windows-сборка отдельно не проверялась. LG TV и Android TV в эту версию не входят.

Это экспериментальная интеграция: Кинопоиск не предоставляет используемый здесь метод выставления оценок как публичный стабильный API. Протокол может измениться; вход может истечь или потребовать проверки на сайте. Плагин не обходит CAPTCHA. Проверка на реальном аккаунте и установленном сервере пользователя необходима перед обычным использованием.

## Как это устроено

- Серверная DLL отслеживает завершённые просмотры и хранит очередь отдельно для каждого пользователя Jellyfin.
- Фильм добавляется после события `PlayedToCompletion`. Сериал предлагается оценить целиком после просмотра всех доступных невиртуальных серий обычного сезона; отсутствующие в медиатеке серии учесть невозможно. Спецвыпуски не запускают предложение. Один ID Кинопоиска предлагается пользователю один раз; «Позже» откладывает его на сутки, «Пропустить» закрывает навсегда.
- File Transformation подключает JavaScript к выдаваемой странице без изменения файлов jellyfin-web. Он автоматически показывает окно оценки после просмотра. Подключение аккаунта и ручная очередь доступны на штатной странице настроек плагина.
- Jellyfin Media Player 1.12.0 получает страницу сервера через собственный загрузчик. Окно оценки и штатные настройки проверены в самом desktop-приложении; специальные флаги запуска для этого не понадобились.
- Идентификатор `kinopoisk` берётся из метаданных. Установленный плагин LinFor можно оставить: он отвечает за поиск и метаданные, этот плагин — за личные оценки.
- Отправка выполняется сервером с авторизованной сессией пользователя. Ошибка отправки не означает, что оценка успешно выставлена.

## Сборка

Нужен SDK .NET 9. Из корня проекта:

```powershell
dotnet build src/Jellyfin.Plugin.KinopoiskRatings/Jellyfin.Plugin.KinopoiskRatings.csproj -c Release
python scripts/package.py
```

Собранная DLL находится в `src/Jellyfin.Plugin.KinopoiskRatings/bin/Release/net9.0/`. Для установки можно указать её через `--dll`; готовая поставка размещается в `dist/`.

Проверки из корня проекта:

```text
dotnet run --project tests/BackendTests.csproj -c Release
node --test tests/frontend.test.cjs tests/frontend-lifecycle.test.cjs
python -m unittest discover -s tests -p "test_*.py" -v
```

Тесты проверяют протокол на имитаторе, хранение, изоляцию пользователей, повторные запросы, жизненный цикл интерфейса и установочные скрипты. Реальная отправка в аккаунт Кинопоиска в эти тесты не входит.

## Установка через каталог Jellyfin

Собственный образ, Python на сервере и изменение `index.html` не нужны.

1. В Jellyfin откройте **Панель управления → Плагины → Репозитории** и добавьте два адреса:
   - File Transformation: `https://www.iamparadox.dev/jellyfin/plugins/manifest.json`
   - Kinopoisk Ratings: `https://raw.githubusercontent.com/VladAysin/jellyfin-kinopoisk-review/main/dist/manifest.json`
2. В каталоге установите **File Transformation** со сборкой под Jellyfin **10.11.5**. Проверка регистрации и обработки HTML выполнена с опубликованной DLL версии **2.5.2.0 / Release-10.11.5.zip**. Не выбирайте сборку для более новой версии Jellyfin.
3. Установите **Kinopoisk Ratings 0.3.0.0**. Зависимость указана в манифесте, но File Transformation рекомендуется установить явно.
4. Перезапустите сервер, обновите страницу браузера с очисткой кеша и полностью перезапустите Jellyfin Media Player.
5. Откройте **Панель управления → Плагины → Мои плагины → Kinopoisk Ratings → Параметры**. Введите Cookie аккаунта Кинопоиска. Подключение относится к тому пользователю Jellyfin, под которым вы вошли сейчас.

Если после просмотра не появляется окно оценки, проверьте журнал сервера: успешное подключение записывает `Kinopoisk Ratings web interface registered with File Transformation`. При отсутствии или несовместимости зависимости сервер продолжит работать, но окно оценки не появится. Обновление самого Jellyfin требует проверки совместимости обоих плагинов.

### Kubernetes

Каталог плагинов и данные Jellyfin должны храниться на PVC и быть доступны процессу Jellyfin на запись. Перезапуск после установки выполняйте через обычный rollout вашего Deployment; ручные изменения образа не нужны. Сохраняйте `kinopoisk-ratings/state.json` и `kinopoisk-ratings/keys` вместе с данными сервера. Поддерживается один экземпляр сервера, пишущий в этот каталог. Для установки нужен исходящий доступ к GitHub и репозиторию File Transformation, для оценок — HTTPS к `graphql.kinopoisk.ru`.

### Обновление с прежних версий

После обновления с 0.2.0 плавающая кнопка исчезнет. Сохранённое подключение и очередь остаются; управлять ими нужно через настройки плагина. Полностью перезапустите клиенты, чтобы они загрузили новый JavaScript.

#### Переход с 0.1.0

Если прежняя версия не устанавливалась, ничего дополнительно делать не надо. Если устанавливалась — не оставляйте вторую DLL в другой папке плагинов. Старый ручной загрузчик распознаётся и не дублируется. Удалить прежнюю вставку можно один раз командой `python scripts/patch-web.py --web-root SERVER_WEB_DIR --remove`; этот скрипт оставлен только для миграции.

## Публикация каталога

Каталожный архив содержит DLL в корне. Сборка и публикация — отдельные действия:

```text
python scripts/package.py --source-url "https://raw.githubusercontent.com/VladAysin/jellyfin-kinopoisk-review/<COMMIT_SHA>/dist/KinopoiskRatings-0.3.0.zip"
```

Вместо `<COMMIT_SHA>` подставьте SHA опубликованного коммита с архивом этой версии. Команда создаёт ZIP, `dist/manifest.json` с MD5 архива и `SHA256SUMS.txt`. Нужно опубликовать эти файлы в репозитории; ссылка архива должна указывать на конкретный коммит с этим архивом. URL каталога использует ветку `main`, URL архива — неизменяемый SHA коммита. Без `--source-url` создаётся только `manifest.template.json`, непригодный для добавления в Jellyfin. Секреты и пользовательские Cookie в публикацию не входят.

## Подключение Кинопоиска

Подключение и оценки изолированы по текущему пользователю Jellyfin. Страница настроек не подключает аккаунт за других пользователей. Используется ручная передача строки Cookie:

1. В обычном браузере откройте `https://www.kinopoisk.ru/` и войдите в нужный аккаунт.
2. Откройте инструменты разработчика → Network/Сеть и перезагрузите страницу. Найдите запрос к `graphql.kinopoisk.ru`, затем в **Request Headers / Заголовках запроса** скопируйте значение заголовка `Cookie` (без слова `Cookie:`).
3. В Jellyfin откройте **Панель управления → Плагины → Мои плагины → Kinopoisk Ratings → Параметры**, вставьте значение и нажмите **Подключить**. Используйте защищённое HTTPS-соединение с Jellyfin, если подключаетесь по сети.
4. Плагин проверяет сессию через профиль Кинопоиска. После успешной проверки можно отправлять оценки. На этой же странице находятся отключение аккаунта и список просмотренного.

Прямой адрес страницы относительно сервера: `/web/#/configurationpage?name=KinopoiskRatings`. Если у сервера настроен Base URL, добавьте его перед `/web/`. Меню администрирования доступно администраторам Jellyfin; сохранение всегда относится к текущему вошедшему пользователю, имя которого показано на странице.

Cookie даёт доступ к вашей сессии: не публикуйте его, не добавляйте в репозиторий и не отправляйте в чат. Он хранится на сервере в зашифрованном виде через ASP.NET Core Data Protection и не возвращается интерфейсу. Доступ администратора к серверу и ключам шифрования остаётся доступом к этим данным. Ключи должны сохраняться между перезапусками, особенно в Docker.

Очередь и зашифрованные сессии находятся в `<Jellyfin DataPath>/kinopoisk-ratings/state.json`, ключи — в подкаталоге `keys`. Ограничьте доступ к этой папке учётной записью сервера. Резервная копия ключей вместе с данными позволяет расшифровать сессии.

Если сессия истекла, войдите на сайте Кинопоиска и подключите обновлённую строку. Отключение аккаунта удаляет сохранённую сессию из плагина; для отзыва самой сессии используйте управление сессиями Яндекса.

## Проверка после установки

Проверьте фильм с заполненным ID Кинопоиска: завершите просмотр, выберите оценку и убедитесь, что она появилась **в вашем аккаунте на сайте Кинопоиска**. Затем повторите в Jellyfin Media Player. Отдельно проверьте «Позже», «Пропустить», выход из пользователя и вход под другим пользователем. Локальные тесты не заменяют эту проверку реального сервера, клиента и аккаунта.

## Удаление

Удалите Kinopoisk Ratings через панель плагинов, перезапустите сервер и обновите клиенты. Файлы веб-интерфейса восстанавливать не требуется. File Transformation можно оставить для других плагинов. Данные очереди и сохранённые сессии автоматически не удаляются; перед удалением плагина аккаунт можно отключить на странице настроек плагина.
